# AVA MINA SPORT — إدارة الدوري (الإصدار 3)

موقع عربي خفيف للموبايل، بنفس الخلفية الداكنة وصورة مارمينا، يعمل بدون سيرفر.

## التغييرات في الإصدار 3

1. **تنس الطاولة وكونكت 4**: بعد انتهاء دور المجموعات، النهائيات تبدأ بالمواجهة بين **أول كل مجموعة وثاني مجموعة أخرى**: A1 × B2 وB1 × A2. مع 3 مجموعات أو أكثر، أول المجموعة يواجه ثاني المجموعة التالية بالتتابع. ولا تظهر خانات تأهل تلقائي غير ضرورية في أول دور للنهائيات.
2. **بلياردو + دومينو + شطرنج + بلاستيشن**: قرعة خروج مغلوب عشوائية. كل اتنين في مباراة، ولو عدد المشاركين *فردي* يبقى فيه **لاعب واحد فقط يتأهل تلقائيًا للدور التالي**. وتتكرر القاعدة في كل دور، من غير خانات (Bye) وهمية.
3. **القرعة القديمة**: لو القرعة كانت اتعملت بكود قديم وبها أكثر من تأهل تلقائي، يظهر زر «تصحيح قرعة النهائيات» أو «تصحيح قرعة خروج المغلوب». يحافظ على أسماء اللاعبين ونتائج المجموعات. إذا كانت نتائج خروج المغلوب اتسجلت من قبل، يظهر تحذير قبل حذف هذه النتائج وإعادة ترتيب المباريات. من الأفضل الاحتفاظ بنسخة احتياطية من بيانات المتصفح قبل أي إصلاح.
4. **التقرير المالي**: يعرض رقمين منفصلين واضحين بدل خلطهم: تحصيل **الدوري الحالي** = عدد لاعبيه × 5 جنيه (بما فيهم الإضافات)، وتحـصيل **يوم إنشاء الدوري من كل الدوريات** التي على نفس الجهاز. 
5. لا يعيد إنشاء الدوريات تلقائيًا ولا يحذف النتائج الموجودة عند التحديث. نسخة 3 تستخدم نفس `localStorage` الموجود في النسخ السابقة.
6. الملفات `index.html` و`app.js` و`styles.css` تحتوي رقم تحديث `v=3` لضمان تحميل النسخة الجديدة عند نشرها.

## الاستعمال

1. سجّل حتى **50 لاعب** في الدوري الواحد، بـ **5 جنيه** لكل تسجيل.
2. اضغط إنشاء القرعة؛ يمكن إضافة لاعبين بعد الإنشاء، والاسمان الجديدان يلعبان ضد بعض، أو ينضمان إلى مجموعة جديدة قبل بدء نهائيات المجموعات.
3. **جينجا**: إقصاء الأسماء حتى يبقى لاعب واحد.
4. **تنس الطاولة / كونكت 4**: مجموعات بحجم 3 عادة، ومجموعات من اثنين عند الحاجة. أول لاعبين يصعدوا من كل مجموعة. في حالة التعادل الكامل بين 3 لاعبين، الكابتن يحدد المتأهلين ويختار الأول ثم الثاني.
5. باقي الألعاب خروج مغلوب عشوائي، والفائز يتأهل للدور التالي.
6. التقرير يظهر الفائز والتاريخ والإجمالي المالي للدوري نفسه واليوم كله منفصلين.

## تحديث GitHub Pages

1. فك ضغط ZIP على الكمبيوتر.
2. في Repository الموقع، اختر **Add file → Upload files**، ثم ارفع **محتويات** المجلد: `index.html`, `app.js`, `styles.css`, `README.md`, ومجلد `assets/`.
3. اعتمد التغييرات عبر **Commit changes** ثم انتظر اكتمال النشر.
4. افتح الموقع وتحقق منه في نافذة خاصة إن ظل المتصفح يعرض نسخة قديمة.

**الحفظ محلي**: لا توجد مشاركة تلقائية بين هواتف مختلفة. لا تحذف بيانات الموقع من المتصفح إذا كنت تريد الاحتفاظ بالدوريات القديمة.
