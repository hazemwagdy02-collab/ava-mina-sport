# AVA MINA SPORT — إدارة الدوري (الإصدار 4)

موقع عربي للموبايل، بخلفية مارمينا الداكنة، يعمل على GitHub Pages بدون سيرفر.

## الجديد في الإصدار 4 — دخول إضافات البنج وكونكت 4 مباشرة إلى خروج المغلوب

- أي لاعب تضيفه **بعد إنشاء قرعة المجموعات** في **تنس الطاولة أو كونكت 4** يسجَّل للدور التالي للمجموعات (خروج المغلوب) مباشرة؛ **لا تُنشأ له مجموعة جديدة** ولا تُعدَّل نتائج المجموعات السابقة.
- كل **لاعبين جديدين** يلعبان ضد بعض في مواجهة خروج مغلوب. تظهر مواجهاتهما في الصفحة حتى قبل انتهاء المجموعات، ويمكن تسجيل فائزها مسبقًا.
- عند الضغط على «بدء خروج المغلوب» بعد اكتمال المجموعات، تضاف هذه المواجهات إلى **نفس الدور الأول** جنبًا إلى جنب مع مواجهات أول وثاني كل مجموعة، مع الاحتفاظ بالنتائج المسجلة.
- لو أضفت **لاعبًا واحدًا فقط** ولم يأتِ لاعب ثانٍ حتى بدء خروج المغلوب، يظهر كتأهل تلقائي (Bye) في هذا الدور، ولا يُحذف اسمه.
- لو كانت النهائيات قد بدأت بالفعل ولم يبدأ الدور التالي بعد، تضاف المواجهات الجديدة لنفس الدور الأول دون تغيير أي نتائج محفوظة.
- **لو دور خروج المغلوب التالي بدأ بالفعل**، لا يمكن تعديل الأدوار السابقة دون المساس بنتائجها؛ لذلك تظهر للمضافين مواجهات خروج مغلوب في مسار إضافي مستقل، والفائز منه يلعب المباراة الحاسمة مع الفائز من المسار الأصلي. وهذا استثناء لحماية النتائج المسجلة.
- تظل الأنظمة الأخرى كما هي: جينجا بنظام الإقصاء؛ البلياردو/دومينو/شطرنج/بلاستيشن خروج مغلوب مع تأهل تلقائي واحد عند العدد الفردي.
- لا يتغير رسم التسجيل: **٥ جنيه لكل لاعب**، بما فيهم المضافون بعد القرعة، بحد أقصى **٥٠ لاعبًا للدوري الواحد**.
- لا يتم حذف الدوريات القديمة أو إنشاء قرعة جديدة عند فتح الإصدار 4. أي مجموعات إضافية أنشأتها النسخ السابقة تظل محفوظة كما هي؛ السلوك الجديد ينطبق على **الإضافات الجديدة**.

## النشر على GitHub Pages

1. افتح ملف `AVA_MINA_LEAGUE_v4_Full_Site.zip` وفك الضغط.
2. على GitHub، افتح مستودع `hazemwagdy02-collab/ava-mina-sport`.
3. استبدل الملفات **`index.html` و`app.js` و`styles.css`** بنسختها الجديدة، أو ارفع محتويات المجلد كاملًا، مع الحفاظ على `assets/`.
4. اضغط **Commit changes** وانتظر اكتمال النشر من **Settings → Pages** أو **Actions**.
5. افتح الرابط المنشور في نافذة خاصة إذا رأيت نسخة قديمة. تمت إضافة `?v=4` في مراجع CSS وJavaScript لتجاوز ذاكرة المتصفح.

**البيانات محفوظة محليًا** على نفس جهاز/متصفح الكابتن في `localStorage`، وليست متزامنة بين الأجهزة. لا تحذف بيانات الموقع أو ملفات المتصفح إذا كنت تريد الاحتفاظ بالدوريات السابقة.
